## 关于本站

### 构建与设计

本站使用 [Hexo](https://hexo.io/) 与 [Stellar](https://xaoxuu.com/wiki/stellar/) 构建，参考 xaoxuu.com 的栏目组织与隐形分界设计。

### 文章如何组织

文章按思考、技术、经验、设计开发、学习分类，并按发表年份自动归档。每篇文章自动带有同名分类标签；其他标签分别表示文章类型（Note、Exp、Tool、Bug）、相关领域与写作视角（Summary、Focus）。

### 内容与更新

文章来自个人学习和实践；项目说明以对应 GitHub 仓库的最新文档为准。
